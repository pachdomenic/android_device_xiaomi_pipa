# Unified Device Tree for Xiaomi Pad 6

The **Xiaomi Pad 6** (codename **"pipa"**) is a premium mid-range tablet from Xiaomi. It was announced in April 2023 and released shortly afterward in multiple global markets. The device features a high-refresh-rate display, Snapdragon 870 SoC, and supports stylus and keyboard accessories, making it suitable for both entertainment and productivity.

## Device specifications

| **Feature**          | **Specification**                                                |
|----------------------|------------------------------------------------------------------|
| **Chipset**          | Qualcomm SM8250-AC Snapdragon 870 (7 nm)                         |
| **CPU**              | Octa-core (1x3.2 GHz Kryo 585 & 3x2.42 GHz & 4x1.8 GHz)          |
| **GPU**              | Adreno 650                                                       |
| **Memory**           | 6/8 GB LPDDR5 RAM                                                |
| **Shipped Android Version** | 13.0 (MIUI Pad 14)                                        |
| **Storage**          | 128/256 GB UFS 3.1 (No microSD slot)                             |
| **SIM**              | Wi-Fi only (No SIM support)                                      |
| **Battery**          | 8840 mAh Li-Po (non-removable), 33W fast charging                |
| **Dimensions**       | 254 x 165.2 x 6.5 mm                                             |
| **Display**          | 11-inch, 1800 x 2880 (16:10) IPS LCD, 144Hz, HDR10, Dolby Vision |
| **Rear Camera**      | 13 MP                                                            |
| **Front Camera**     | 8 MP                                                             |
